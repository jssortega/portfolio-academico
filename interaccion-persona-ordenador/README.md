# Interacción Persona-Ordenador

Repositorio con proyectos y prácticas desarrollados para la asignatura **Interacción Persona-Ordenador**.

## Descripción

En esta asignatura se trabajó el diseño e implementación de interfaces gráficas centradas en la interacción con el usuario, prestando atención a la usabilidad, organización de ventanas, navegación entre acciones y presentación de la información.

Los proyectos desarrollados están orientados a aplicaciones de escritorio con interfaces interactivas, formularios, menús, cuadros de diálogo y gestión de datos, aplicando principios básicos de diseño de interfaces y experiencia de usuario.

## Tecnologías utilizadas

- Java
- Java Swing
- NetBeans GUI Builder
- Gestión de eventos
- Persistencia simple en archivos TSV
- Internacionalización de interfaces
