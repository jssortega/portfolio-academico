# Estructuras de Datos

Repositorio con prácticas desarrolladas en C++ para la asignatura **Estructuras de Datos**.

## Descripción
En esta asignatura se trabajaron conceptos fundamentales de programación y organización de datos en memoria, utilizando C++ y programación orientada a objetos.

A lo largo de las prácticas se implementaron distintas estructuras de datos y aplicaciones relacionadas con gestión de información, búsqueda, almacenamiento y procesamiento eficiente de datos.

## Tecnologías utilizadas
- C++
- Programación orientada a objetos
- STL (`vector`, `list`, `map`, etc.)
- Manejo de ficheros
- Algoritmos de búsqueda y organización de datos


## Contenido de cada práctica
Dentro de cada carpeta se incluye, según el caso:
- código fuente (`.cpp`)
- archivos de cabecera (`.h`)
- ficheros de datos
- documentación de la práctica
- capturas o resultados

## Compilación
La compilación depende de cada práctica. En general, los proyectos están implementados en C++ y pueden compilarse con `g++` incluyendo los archivos fuente y cabeceras correspondientes.

Ejemplo genérico:

```bash
g++ *.cpp -o programa
