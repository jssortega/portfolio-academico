# Sistemas Operativos

Repositorio con prácticas y proyectos desarrollados para la asignatura **Sistemas Operativos**.

## Descripción

En esta asignatura se trabajó el uso de herramientas y conceptos fundamentales de los sistemas operativos, con especial atención a la automatización de tareas, el uso de la terminal y la programación de scripts en Bash.

A lo largo de las prácticas se desarrollaron programas y utilidades orientados a la gestión de archivos, ejecución de procesos, uso de permisos, procesamiento de entradas y salidas, y automatización de tareas comunes en entornos Linux.

## Tecnologías utilizadas

- Bash
- Linux
- Shell scripting
- Comandos de sistema y utilidades Unix
