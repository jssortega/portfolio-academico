# Desarrollo de Software para Dispositivos Móviles

Repositorio con aplicaciones desarrolladas en Flutter para la asignatura **Desarrollo de Software para Dispositivos Móviles**.

## Descripción
En esta asignatura se trabajó el desarrollo de aplicaciones móviles multiplataforma utilizando Flutter y Dart.

Los proyectos realizados incluyen interfaces gráficas, navegación entre pantallas, gestión del estado, interacción con el usuario y lógica de aplicación para distintos tipos de apps móviles.

## Tecnologías utilizadas
- Flutter
- Dart
- Material Design
- Widgets Stateful y Stateless
- Gestión de eventos y animaciones

## Contenido de los proyectos
Cada carpeta contiene el código fuente de una aplicación móvil desarrollada en Flutter.  
Según el proyecto, puede incluir:
- archivos en `lib/`
- archivo `pubspec.yaml`

## Ejemplo de funcionalidad implementada
En el proyecto `pong-flutter` se implementa:
- una pantalla principal de inicio,
- una zona de juego interactiva,
- movimiento de pelota,
- desplazamiento horizontal de la raqueta mediante gesto,
- detección de colisiones,
- sistema de puntuación y aumento de dificultad,
- reinicio de partida tras perder.
