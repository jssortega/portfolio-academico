# Multimedia

Repositorio con proyectos desarrollados para la asignatura **Multimedia**.

## Descripción
En esta asignatura se trabajó el desarrollo de aplicaciones orientadas al procesamiento y gestión de contenido multimedia, especialmente audio e interacción con dispositivos de entrada y salida.

## Tecnologías utilizadas
- C#
- WPF
- NAudio
- TagLib
- Gestión de eventos e interfaces gráficas

## Estructura del repositorio
- `reproductor-musica-csharp/`: aplicación de escritorio desarrollada en C# con funcionalidades de reproducción de audio, lectura de metadatos, grabación, gestión de micrófonos y pads de sonido

## Funcionalidades destacadas
El proyecto principal de la asignatura incluye:
- reproducción de archivos MP3 y WAV
- pausa y cambio de canción
- barra de progreso de reproducción
- lectura de título, artista y carátula
- grabación de audio desde micrófono
- selección de dispositivos de entrada
- mute y control de volumen de micrófonos
- pads para asignar y lanzar sonidos
