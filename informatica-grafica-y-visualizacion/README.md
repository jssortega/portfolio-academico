# Informática Gráfica y Visualización

Repositorio con proyectos y prácticas desarrollados para la asignatura **Informática Gráfica y Visualización**.

## Descripción

En esta asignatura se trabajó el desarrollo de aplicaciones gráficas en C++ orientadas a la representación, visualización e interacción con escenas 2D y 3D.

A lo largo de las distintas prácticas se implementaron conceptos fundamentales de informática gráfica, incluyendo modelado geométrico, cámaras, proyecciones, renderizado, interacción mediante teclado y ratón, y gestión de escenas.

## Tecnologías utilizadas

- C++
- OpenGL
- GLUT / FreeGLUT
- CMake
- Conan
