# Portfolio Académico

Repositorio personal donde recopilo proyectos y prácticas desarrollados durante el grado en Ingeniería Informática.

## Sobre este portfolio

Este repositorio reúne trabajos realizados en distintas asignaturas del grado, organizados por carpetas según la materia correspondiente.

El objetivo es mostrar de forma estructurada proyectos desarrollados en áreas como programación, desarrollo móvil, multimedia, informática gráfica, visión por computador, interacción persona-ordenador y sistemas operativos.

## Trabajo de Fin de Grado

### Aplicación móvil para la gestión intuitiva de finanzas personales

Como proyecto final del grado desarrollé una aplicación móvil orientada a la gestión personal y colaborativa de finanzas.

La aplicación permite registrar ingresos y gastos, gestionar múltiples cuentas, compartir cuentas entre varios usuarios y consultar estadísticas financieras. Además, incorpora movimientos recurrentes, conversión dinámica de divisas, internacionalización y una herramienta de previsión para estimar la situación financiera futura.

El proyecto fue desarrollado principalmente con **Flutter y Dart**, utilizando **Firebase** para autenticación, almacenamiento y persistencia de datos en tiempo real.

➡️ [Ver proyecto](./tfg/finance_tfg/)
