# Procesamiento de Información Visual

Repositorio con prácticas y proyectos desarrollados para la asignatura **Procesamiento de Información Visual**.

## Descripción

En esta asignatura se trabajó el análisis y procesamiento de imágenes mediante técnicas de visión por computador, utilizando Python y notebooks interactivos.

A lo largo de las distintas prácticas se abordaron conceptos como filtrado, segmentación, detección de bordes, transformaciones, análisis de características visuales y detección de objetos en imágenes.

## Tecnologías utilizadas

- Python
- Jupyter Notebook
- OpenCV
- NumPy
- Matplotlib
